# Frontend gate

Frontend implementation is intentionally deferred until the backend gate is demonstrated with real Harnyx evidence. Required evidence includes official artifact validation, a successful Docker-backed local-eval run, persisted benchmark output, a selective SLAI-derived candidate that beats B0 on reward-relevant metrics, and an untouched holdout result.

The existing `frontend/assets/` brand files are retained for the later BIMAP-derived observability UI. No dummy benchmark data, placeholder controls, or speculative score dashboard is permitted.
